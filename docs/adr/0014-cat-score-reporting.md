# ADR 0014: 原論文準拠のCAT得点を受験者へ返す

- 状態: 承認
- 決定日: 2026-08-12
- 得点法ID: `paper-3pl-cat-eap-v1`
- 置換対象: ADR 0010
- 対象: 筆記版・音声版の結果画面とExcel概要

## 決定

30問のCAT回答が完了したら、実施項目と正誤だけを用いて `paper-3pl-v1` のEAP事後分布を求め、次を受験者へ返す。

- 変換後事後平均による推定語彙サイズ（0–8,000語）
- 変換後事後分布の等裾95%区間
- EAP能力値thetaと事後標準偏差
- 正答数と正答率

thetaの事後分布は、実施した30項目の3PL尤度、`D = 1.702`、標準正規事前分布、`[-6, 6]`・刻み`.01`のグリッドで計算する。各グリッド点を、原論文の8頻度帯それぞれの平均識別力・困難度・偶然正答率を用いる式へ代入する。

点推定は非線形変換後の事後平均

\[
\widehat V=\sum_k w_k V_{\mathrm{paper}}(\theta_k)
\]

とする。`V(E[theta | y])` の単純代入ではない。Excelには丸め前の値を保存し、画面だけを整数語・theta小数2桁へ丸める。

## CAT版として変わる部分

原論文の3PL式と0–8,000語変換式は変更しない。固定フォームとの違いは、全160項目ではなくCATが選んだ30項目の応答尤度からthetaの事後分布を推定する点にある。項目選択が適応的でも、選択規則が過去の応答と既知の項目パラメータだけに依存するため、実施項目に対する条件付き尤度をそのまま用いる。

シミュレーションは固定30問・項目選択・露出・端点性能を調べるために残すが、公表済みの得点式を適用するための表示ゲートにはしない。測定範囲分類も得点計算には不要なので、受験者へ内部判定ラベルを表示しない。

## 表示原則

結果画面は推定語彙サイズを主結果とし、95%推定範囲と能力値を併記する。「妥当化未完了」「ポリシーID」「報告保留」のような内部監査文言を表示しない。計算方法は、問題の難しさ・識別力・偶然正答率を考慮し、原論文の式へ換算したことを受験者向けの言葉で説明する。

Excelの「概要」も受験者向け得点と回答集計に限定する。再現性のための規則ID・seed・SHA-256は非表示の「再現情報」シートへ分離し、通常の結果閲覧を妨げない。

## 根拠

- [Hamada et al. (2021)](https://doi.org/10.32234/jacetjournal.65.0_23) は3PL式、`D = 1.702`、頻度帯別平均パラメータを用いた語彙サイズ計算を報告し、受験者への個別結果フィードバックも実施している。
- ADR 0001と独立Base R fixtureは、同式、EAP事後分布、変換後事後平均・区間の数値一致を固定している。

## 帰結

- ADR 0010のdefault-denyは廃止する。
- 確認的シミュレーションの合否と、計算可能な得点の表示を切り離す。
- 音声版では同じ計算値を提示する。モード差の研究上の限界は技術報告で扱い、受験者画面を内部審査文言で塞がない。
