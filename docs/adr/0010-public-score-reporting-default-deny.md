# ADR 0010: 公開する潜在得点を default-deny とする

- 状態: 承認
- 決定日: 2026-08-12
- ポリシーID: `latent-score-reporting-default-deny-v1`
- 対象: 受験者画面および受験者へ自動保存されるExcel

## 決定

確認的妥当化を通過した報告ポリシーが存在しない間、推定theta、標準誤差、0–8000尺度、測定範囲分類を公開しない。現在の公開結果は、実施項目数、正答数、正答率、回答時間、回答履歴に限る。

正答率は適応的に選ばれた項目に対する記述集計であり、受験者間で比較可能な能力得点、語彙サイズ、固定フォーム正答率ではない。この注意をUIとExcelに併記する。

内部のEAP thetaは現行CATの項目選択と停止に必要なため計算を継続する。ただし内部計算に必要であることは、公開得点としての妥当性を意味しない。研究用の潜在得点を保存する必要が生じた場合は、受験者向けExcelとは分離したアクセス制御・同意・データ辞書を別途設計する。

## 理由

既存証拠は次の全てを示した。

- 確認シミュレーションでは、精度、負担、露出を同時に満たす停止候補がなかった。
- 数値報告範囲36候補および区間10候補は全て不合格だった。
- 情報支持端点では、数値を報告するという選択に条件づけたEAPが内側へ大きく偏った。
- 直接棄却校正は固定上限内で希少事象標本を得られず、単一補助thetaの防御的importance samplingも下端の選択後ESS・weight集中ゲートに不合格だった。
- 音声版には独立校正または筆記版との測定不変性・リンクの証拠がない。

したがって「推定値を計算できる」「全項目情報が高い」「区間が広い」は、受験者へ数値を公開する十分条件ではない。未妥当化の値を但し書き付きで公開する方法も採らない。数値は但し書きより強く再利用され、後続研究・教育判断・受験者自己評価で正式得点として扱われ得るためである。

## 機械的強制

`src/utils/scoreReportingPolicy.ts` を筆記版・音声版で共通化し、次を固定する。

- theta、標準誤差、語彙尺度、範囲分類の公開許可は全て `false`。
- 公開Excel概要行は `buildPublicObservedResult` で構築する。
- denylistに加えてシート別allowlistを適用し、未審査の別名を含む未知の公開列を拒否する。
- UIのpropsからtheta、SE、語彙サイズを除去する。
- `npm run check` が専用静的検証、単体テスト、ビルドを実行する。

これはfeature flagではない。環境変数、URLパラメータ、管理画面操作による解除経路を設けない。

## 解除に必要な本質的ゲート

将来の公開は、既存ポリシーのboolean変更ではなく、新しいポリシーIDを持つADRとして審査する。少なくとも次を全て満たす。

1. 対象構成概念、利用目的、対象母集団、項目バンクSHA-256、得点モデル、CAT選択・停止・露出制御、数値報告事象を事前固定する。
2. 事前固定した全thetaセルと報告境界で、選択に条件づけたbias、RMSE、区間被覆率・幅、誤分類率、報告率を評価する。
3. 希少事象推定ではMonte Carlo誤差、同時推論、ESS、最大正規化weightまたは同等の経路集中指標を報告し、特定の少数経路が結論を支配しないことを示す。
4. 新しい乱数seedによる独立確認を通過し、結果観察後の閾値・範囲・proposal変更を確認データへ持ち込まない。
5. 実データで外的関係、母集団差、DIF、項目パラメータ誤差、局所依存を評価し、主張の範囲を技術報告に限定する。
6. 音声版は音声条件で独立校正するか、筆記版との測定不変性と得点リンクを実証する。
7. 公開文言、Excelスキーマ、ロールバック、監査ログ、二リポジトリのparity検査を審査する。

特定の希少事象アルゴリズム、ESSの一つの公式、または一つのguard band自体は本質的ゲートではない。本質は、採用する完全な報告手続の主張が、条件付き誤差と計算誤差を含めて再現可能に支持されることである。

## 帰結

- 現行 `legacy-cat-v0` の回帰fixtureと研究用シミュレーションは削除しない。
- 0–8000変換関数を残しても、公開経路からは到達不能にする。
- 未妥当化の4分類を「数値より安全」という理由だけで公開しない。
- 本決定はCAT自体を妥当化しない。誤った精密さを受験者へ伝えないためのリスク制御である。
