Design contract

修正を支配する6原則

1. 推定対象を先に決める

θ、期待正答数、既知語数を区別し、利用目的と損失関数を明文化する。

2. 数式を版管理する

score_model_id、係数D、事前分布、項目バンク版を結果へ保存する。

3. 不確実性を報告する

1語単位の点推定ではなく、事後平均・中央値・95%区間を用途に応じて示す。

4. シミュレーションを再現可能にする

条件、乱数生成器、seed、項目バンクhash、コードcommitを全て成果物へ残す。

5. モデル内精度と妥当性を分ける

Monte Carlo性能だけで「語彙サイズとして妥当」と結論しない。実データで検証する。

6. 音声版を別モードとして扱う

筆記版の値を無条件に流用せず、仕様固定、校正、DIF・モード等価性を確認する。

項目バンク診断要約 / 完全な診断JSON

exploratory estimator sensitivity complete

推定法感度分析の契約

EAP（標準偏差1・2の正規事前分布）、MAP、bounded MLE、Warm WLEを候補として実装し、 独立base R計算と混合・全正答・全誤答パターンで照合した。Warm WLEは log L(theta) + 0.5 log I(theta)を直接最大化し、簡略近似は用いない。 全正答・全誤答のbounded MLEが境界に達することも明示的に記録する。

同一の項目・反応経路15,000本で感度分析した結果、bounded MLEは最大33%が境界に達した。 Warm WLEは最大絶対biasが20問で.132、30問で.095と小さかったが、 低端RMSEはそれぞれ.507、.461であり採用確定には至らない。 推定法候補ADR / 感度分析要約。 次は条件付き露出制御と測定範囲判定を設計する。

unconditional SH is insufficient

直接露出制御と頻度帯blueprint

項目別実施確率を8回のシミュレーションで校正するSympson–Hetter法を実装した。 3設計・計94,500 CATの探索では、最大周辺露出を従来の.356から .256–.260へ低減したが、厳密な.25ゲートには届かなかった。 さらにtheta条件別最大露出は.998–1.000であり、周辺露出だけでは 特定能力帯での集中を防げない。

low/middle/highを各2問以上とする3帯候補は、各Levelを最低1問とする候補より 精度低下が小さかった。後者は棄却し、3帯候補も内容専門家の承認までは探索仕様とする。 露出制御ADR / 探索結果要約。

information-support diagnostic complete operational reporting range unvalidated

項目バンク情報支持範囲と報告保留契約

全160問の情報換算SDが.30以下となる、theta 0を含む連結成分を厳密に求めた。 境界はtheta [-2.903165, 3.427993]で、base Rの独立実装と 1e-9以内で一致した。対応する原論文モデル得点は約[919.80, 7993.32]だが、 真の既知語数境界とは解釈しない。

事後確率によるbelow-range / within-range / above-range / indeterminateの 4分類を実装したが、全結果にexploratory-not-for-score-reportingを付与する。 全項目情報の1/sqrt(I)は20項目CATのRMSEではないため、次は境界付近を密にした common-pathシミュレーションと独立確認を行う。 測定範囲ADR / 診断要約。

range-reporting: 0 / 36 passed

範囲判定は機能、数値区間の校正は未達

事前固定した27 theta条件・27,000 CAT・486,000候補事後評価では、36候補の合格は0だった。 20候補は区間被覆率だけが不合格で、狭い範囲候補は範囲外の誤った数値報告を概ね抑制した。 しかし数値報告ケースの条件付き95%被覆率は.918–.9896に分散し、 Wilson区間を含む全セル基準を満たさなかった。

結果を見た後に被覆率基準や境界不問帯を緩めず、確認実験への候補選択を保留する。 次はrange・点推定と分離して、simulation-calibrated intervalとlikelihood/WLE互換区間を 共通経路で比較する。 範囲報告ADR / 探索結果要約。

interval calibration: 0 / 10 passed

区間単独の校正では選択後の被覆率を保証できない

事前固定した校正74,000パスと独立評価54,000パスで、equal-tail EAP、固定尤度比、 校正尤度比、校正Warm重み付き尤度、EAP Neyman区間を比較した。base Rで数値核を独立照合したが、 10候補の合格は0だった。30問候補のbias・RMSE・幅は良好でも、全thetaセルの90% Wilson同等性と 片側逸脱率を同時には満たさなかった。

校正分布は各thetaの全生成パスを対象とする一方、評価は範囲分類・区間妥当性・情報支持範囲を通過して 数値報告されたパスに条件づける。この選択で標本分布が変わり得るため、次は区間単独ではなく 選択・区間を合わせた完全な報告手続を校正する。確認実験と本番切替は保留する。 区間校正ADR / 探索結果要約 / 次期選択的報告設計。

selective reporting: rejected

情報支持端点では選択後の点推定が内側へ偏る

27校正セル・303,179校正CATと、両端点各10万件を含む320,000独立評価CATで、 数値報告という選択事象に条件づけたEAP Neyman区間を検証した。端点被覆率は equal-tail基準の約.535/.472から.979/.987へ改善したが、 過被覆・幅・空反転fallbackに加え、選択後EAP biasが下端+.340、上端-.439となり不合格だった。

境界内に推定された経路だけを選べば、端点の推定分布が内側へ寄るのは構造的である。 区間を広げても点推定biasは修復できない。次は全項目情報支持範囲と、CATが点推定を報告する 内側の運用範囲を分離し、guard band候補を事前固定して比較する。13万CATの実行可能性pilotでは、 直接棄却法の校正上限内に必要な選択例を得られない8セルが判明したため、本評価は未着手である。 続く36万CATの防御的importance sampling検証は、全weight恒等式と6直接照合には合格したが、 下端の選択後ESSが7.35–238.61に留まり、proposalを棄却した。 選択的報告ADR / 探索結果要約 / 次期選択補正点推定設計 / 実行可能性pilot要約 / 校正方式ADR / importance検証要約 / importance ADR。

public latent scores default-deny

未妥当化の数値得点を公開経路から遮断

確認的妥当化を通過した報告ポリシーが存在しないため、受験者画面と自動Excelから theta、標準誤差、0–8000尺度、未妥当化の範囲分類を除去した。内部thetaは項目選択と 停止のためだけに維持し、公開結果は実施項目の回答集計に限定する。正答率も適応的に 選ばれた項目の記述集計であり、比較可能な能力得点ではないと明示する。

latent-score-reporting-default-deny-v1 はfeature flagではない。 専用テストと静的検証がUI propsとExcelフィールドへの潜在得点の再混入を拒否する。 解除には新しいポリシーID、条件付き性能とMonte Carlo誤差の事前固定評価、独立確認、 実データ妥当化、音声版のモード固有証拠が必要である。 公開得点default-deny ADR。

research administration fixed at 30 not score-valid

未妥当化SE停止を研究実施経路から除去

旧アプリのSE ≤ .40 / min20 / max30は、確認試験で平均20.04問、 99.68%がprecision停止した一方、最悪bias .392、RMSE .478、 95%被覆率.822で不合格だった。この事後SDに実施長を決めさせず、 研究用手続をpaper-3pl-v1 / fixed30 / randomesque-5へ固定した。

fixed-30も得点ゲートには不合格であり、research-baseline-not-score-validとする。 各実施のseed、停止理由、手続ID、項目バンクSHAをExcelへ保存し、確認計画との構造一致を CIで検査する。項目露出は秘匿ゲートではなく、項目利用偏在・精度・再受験効果の診断として残す。 研究実施規則ADR。

audio stimulus protocol fixed mode validity not established

端末依存TTSを除去し、音声刺激の提示条件を固定

日本語問題語は視覚提示のみ、英語4選択肢は同梱MP3のみとした。A→B→C→Dの順に 各1回を最後まで聞くまで回答できず、成功後の再生・同時再生・端末TTS fallbackを禁止する。 音声失敗時だけ再試行し、別voiceへ無言で置換しない。選択肢順は研究実施seedから再現可能にした。

160項目の640選択肢セルは重複を除く639語で、同梱MP3も639件、欠損・余剰・slug衝突は0件だった。 全資産をファイル別SHA-256からなるmanifestで固定した。ただし生成時のgTTS version・voice IDは 記録がなく、発音・音量・無音区間の専門QA、実施環境仕様、音声条件での独立校正は未完了である。 音声刺激ADR。
