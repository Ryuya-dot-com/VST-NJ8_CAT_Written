# ADR 0011: 研究用実施規則をfixed-30へ固定する

- 状態: 承認（研究用ベースライン）
- 決定日: 2026-08-12
- 実施規則ID: `research-fixed30-randomesque5-paper3pl-v1`
- 妥当化状態: `research-baseline-not-score-valid`
- 対象: 筆記版・音声版の研究データ収集

## 決定

現行アプリの可変長規則 `minimumItems = 20`, `posterior SD <= .40`, `maximumItems = 30` を研究実施経路から外す。代わりに、次の手続を固定する。

- 30問固定長。事後SDによる早期停止は行わない。
- 項目反応モデルとEAP更新は `paper-3pl-v1`（3PL、`D = 1.702`、`N(0,1)`事前、thetaグリッド `[-6,6]`, step `.01`）を用いる。
- 初問はLevel 3–5から無作為抽出する。
- 以後はpaper-3PL項目情報量の上位5項目から一様無作為抽出するrandomesque-5とする。同情報量は項目index昇順でtie-breakする。
- Level 7–8が2問未満の間は、利用可能なら同レベル候補内でrandomesque-5を行う。
- 1実施につき暗号学的乱数源から32-bit seedを1個生成し、その後の初問・項目選択は`mulberry32-v1`で再現可能にする。
- Excelへ実施規則ID、妥当化状態、得点モデルID、内部推定法ID、項目バンクSHA-256、確認計画・結果・判定の各SHA-256、選択法、固定長、乱数生成器ID、seed、停止理由を保存する。

これは得点規則の採用ではない。ADR 0010の潜在得点default-denyを維持し、theta・SE・0–8000尺度・範囲分類は受験者へ返さない。

## 証拠と限界

`confirmation-v1` は15 theta条件 × 5,000反復 × 7候補、計525,000 CATを事前固定基準で比較した。合格候補は0件だった。

旧規則に近い `SE .40 / min20 / max30 / maximum-information` は平均20.04問で、99.68%がprecision停止した。しかし最悪条件でbias `.392`、RMSE `.478`、95%被覆率 `.822`となり、未妥当化の事後SDが実施長を決定する合理性を示せなかった。

`fixed30 / randomesque-5` は候補中で最悪bias `.363`、RMSE `.436`と最小だったが、被覆率 `.842`、平均30問、最大露出 `.381`で、得点・負担・当初の露出基準には不合格だった。したがって「30問なら妥当」とは解釈しない。

それでも研究ベースラインとしてfixed-30を選ぶ理由は次のとおりである。

1. 未妥当化の精度尺度による情報依存停止を除き、全参加者に同じ観測回数を適用できる。
2. 検討候補中では端点誤差が最小であり、20問候補より多くの反応情報を保存できる。
3. 既存の選択的報告・希少事象研究がfixed-30/randomesque-5を共通候補としており、方法論比較を一貫させられる。
4. seedと完全な応答・選択順序を保存するため、実施経路を再構成できる。

固定長は停止規則の妥当化問題を単純化するが、EAP端点bias、区間誤校正、項目バンク情報不足、母集団差、DIF、局所依存、音声モード非等価性を解決しない。

## 機械的強制

- `src/utils/researchAdministrationPolicy.ts` に手続を閉じた定数として置く。
- 単体テストが30問停止、同seed再現、項目非重複、上位5項目選択、Level 7–8制約、異常入力拒否を検査する。
- `scripts/verify-research-administration.ts` が実アプリから旧EAP・旧選択・旧SE停止への参照が消えていることを確認する。
- 同スクリプトが `confirmation-v1/fixed30-randomesque5` と全構造フィールドを照合する。
- 確認計画、シミュレーション結果、判定結果のSHA-256を照合し、合格候補が0件かつfixed-30がbias・RMSE・被覆率ゲートに不合格であることを強制する。
- 項目バンクSHA-256 `ed058c8b87ef951c70512f89ac2ba708f18db983dd5b449b201e9b2dc97d0d47` を照合する。
- 筆記版・音声版の共通実装をrepository parity manifestで固定する。

## 音声版

音声版でも同じ研究実施アルゴリズムを用いるが、これは筆記項目パラメータが音声条件で妥当であることを意味しない。音声版の実施規則とログを揃える目的に限る。独立校正または測定不変性・得点リンクが得られるまで、音声版潜在得点は引き続き非公開とする。

## 将来の変更ゲート

可変長へ戻す場合は、停止統計量、最小・最大長、項目選択、推定量、報告手続を一体として事前固定し、新seedの確認試験を通す。固定30問から別の固定長へ変える場合も、新しい実施規則IDを発行し、過去データを上書きしない。

## 帰結

- `legacy-cat-v0` と旧停止関数は回帰・比較研究用に残すが、実アプリからは到達不能にする。
- 項目露出率はバンク秘匿の公開ゲートではなく、項目利用偏在・精度・再受験効果を評価する方法論的診断として残す。
- 30問完了前の項目バンク枯渇は異常停止として記録する。
